v本地生词本

把读到的英文，变成第二天要复习的单词。

复制一句英文，它自己挑出生词、查好释义、排进复习队列。释义来自本机的 40 万条离线词典，不联网也不花钱。每天早上再送来 10 篇科技商业新闻，读着读着词就攒起来了。

一个词长这样

mitigate/ˈmɪtɪgeɪt/★★★
make less severe or harsh

We need to mitigate the downside risk.

The company mitigated the damage quickly.

Planting trees mitigates urban heat.

左边是词，右边是三个例句。中文一律藏起来 —— 鼠标停上去才浮出来， 逼自己先用英文理解。星星记录背过几次。

mitigate /ˈmɪtɪgeɪt/
vt. 减轻，缓和

阅读时鼠标停在任意单词上，本机词典即刻给出中文，不打断阅读。

复制一句话之后发生了什么

  1. 护栏先拦一道

    超长文本、中文、链接、代码、以及任何像密码或密钥的内容，直接忽略，绝不入库。

  2. 词频表筛掉认识的

    近万条词频排名，常见词剔除；已掌握的、以及你手动删过的词也跳过。

  3. 老朋友直接 +1

    已经收过的词只增加遇见次数并顶到列表最前，不重复建条目，一次调用都不花。

  4. 剩下的查离线词典

    释义、音标、词性、词形还原全部本地完成。bearings 会归到 bear。

  5. 排进复习队列

    间隔重复：答对一次隔 1 天，然后 3、8、22、64 天，到 60 天自动毕业，不再打扰。

页面上不出现中文，为的是逼出英文思维。任何单词双击即收藏。

数据都在你自己机器上

词库
~/.vocab/vocab.db — 单文件，拷走即备份
离线词典
401,258 条（ECDICT），44 MB，一次导入
词频表
9,894 条，用来判断哪些词你肯定认识
依赖
单文件 Python，只用标准库，无需 pip install
联网
只有抓新闻和写例句才联网；不配密钥也能完整使用

装起来

# 拿到代码
git clone git@github.com:USER/vocab.git ~/.vocab
ln -s ~/.vocab/vocab.py ~/.local/bin/v && chmod +x ~/.vocab/vocab.py

# 导入离线词典（ecdict.csv 来自 skywind3000/ECDICT）
v dict import ecdict.csv

# 起服务：网页 + 剪贴板守护
v serve --open
v watch

macOS 上可以把两个进程交给 launchd，开机自动运行，此后只用打开网页。

自用工具，写给一个想靠读英文资讯来记单词的人。
离线词典 ECDICT 与词频表均来自公开数据源，新闻只保存标题与自动生成的摘要，正文回原站阅读。
